## 1. 产品概述

### 1.1 产品背景
用户在日常生活中有大量高频、小额的消费行为（餐饮、交通、购物等），但普遍存在以下痛点：

- **记不住**：消费后忘记记录，月底对不上账；
- **懒得记**：传统记账流程繁琐（打开 App → 选分类 → 输入金额 → 备注 → 保存），坚持不下来；
- **看不懂**：记了一堆流水，却不知道钱花在哪、有没有超支；
- **管不住**：没有预算约束和提醒，消费缺乏节制。

### 1.2 产品定位
一款**极简、高效、有洞察**的个人记账工具，核心理念：

> **3 秒记一笔，1 眼看清钱去哪。**

### 1.3 产品目标
| 阶段 | 目标 |
|---|---|
| 短期（V1.0） | 让用户每天愿意记账：记账流程 ≤ 3 步，单笔记账 ≤ 5 秒 |
| 中期（V1.x） | 让用户看懂消费：多维度报表 + 预算管理 |
| 长期（V2.0+） | 让用户管好钱：智能分析、消费建议、多账户资产管理 |

### 1.4 目标用户
| 用户画像 | 特征 | 核心诉求 |
|---|---|---|
| 学生党 | 生活费固定，月光风险高 | 控制预算，不超支 |
| 职场新人 | 有攒钱意愿，消费场景多 | 快速记账，月度复盘 |
| 家庭记账者 | 收支条目多，注重结余 | 分类清晰，报表完整 |

## 2. 需求范围

### 2.1 V1.0 功能范围（MVP）
✅ 快速记账（支出/收入）
✅ 账单流水（按日/月查看、编辑、删除）
✅ 分类管理（预置分类 + 自定义）
✅ 统计报表（月度收支、分类占比、趋势）

❌ 多人共享账本
❌ 云同步与多端登录

## 3. 功能需求详述

### 3.1 快速记账（核心功能，P0）

**功能描述**：用户打开 App 后能以最短路径完成一笔记账。

**交互流程**：
```
首页点击「+」→ 数字键盘输入金额 → 选择分类（宫格，一次点击）→ 保存
（可选：备注、日期、收入/支出切换）
```

**功能要点**：
| 编号 | 需求点 | 说明 | 优先级 |
|---|---|---|---|
| F1-1 | 金额输入 | 默认弹出数字键盘，支持两位小数，支持「+」「-」简单算式（如 15+8） | P0 |
| F1-2 | 收支切换 | 默认「支出」，可切换「收入」 | P0 |
| F1-3 | 分类选择 | 宫格图标展示，常用分类按使用频率靠前排序 | P0 |
| F1-4 | 日期选择 | 默认今天，可回溯补记历史日期 | P0 |
| F1-5 | 备注 | 选填，≤ 50 字 | P1 |
| F1-6 | 连续记账 | 保存后提供「再记一笔」入口 | P1 |
| F1-7 | 记账提醒 | 每日固定时间（默认 21:00，可配置/关闭）推送提醒 | P1 |

**验收标准**：
- 从打开 App 到完成一笔记账 ≤ 5 秒、≤ 3 次点击（不含输入金额）；
- 金额必填且 > 0，非法输入给出即时提示。

**功能描述**：按时间维度查看、管理所有记账记录。

| 编号 | 需求点 | 说明 | 优先级 |
|---|---|---|---|
| F2-1 | 首页月账单 | 默认展示本月流水，按日分组，每日显示小计（支出/收入） | P0 |
| F2-2 | 月份切换 | 顶部快捷切换月份，展示当月总支出/总收入/结余 | P0 |
| F2-3 | 编辑记录 | 点击单条记录可修改金额、分类、日期、备注 | P0 |
| F2-4 | 删除记录 | 左滑删除，需二次确认 | P0 |
| F2-5 | 搜索筛选 | 按关键词（备注）、分类、金额区间筛选 | P2 |

### 3.7 用户账户（V1.0.1 新增，P0）

**功能描述**：以「账户 + 密码」形式提供登录/注册，作为进入 App 的门禁，并实现**多账号数据隔离**（同一台设备可供多人分别记账，互不可见）。

> **实现说明**：为延续本产品「纯本地、离线、隐私」的定位，V1.0.1 采用**本地账号**方案——账户与账本均存于本机浏览器（localStorage），**不搭建后端、不上传服务器**。因此登录本质是「本机账本锁 + 多账本切换」，暂不支持跨设备登录（跨设备与云同步仍规划在 V2.0）。

| 编号 | 需求点 | 说明 | 优先级 |
|---|---|---|---|
| F7-1 | 注册 | 账户名（≥ 2 位）+ 密码（≥ 6 位）+ 确认密码；账户名不可重复 | P0 |
| F7-2 | 登录 | 账户名 + 密码校验，成功后进入 App | P0 |
| F7-3 | 登录态保持 | 登录后记住会话，再次打开无需重复登录 | P0 |
| F7-4 | 退出登录 | 「我的」页提供退出入口，退出后回到登录页；本机账本数据保留 | P0 |
| F7-5 | 密码安全 | 密码经**加盐哈希**后存储，不保存明文（优先 Web Crypto SHA-256，不可用时回退简易哈希） | P0 |
| F7-6 | 账本隔离 | 每个账户拥有独立账本（流水/预算/分类互不影响） | P0 |
| F7-7 | 历史数据迁移 | 首个注册账户自动继承 V1.0 单账本的既有数据，避免升级后数据丢失 | P1 |

**验收标准**：
- 未登录时无法进入记账主界面；
- 不同账户登录后各自只能看到自己的账本；
- 刷新/重开页面仍保持登录态，直至主动退出；
- 密码在 localStorage 中不以明文形式出现。

## 4. 页面结构与信息架构

```
底部 Tab 导航（3 个）
├── 📒 明细（首页）
│    ├── 月份切换 + 收支概览卡片
│    ├── 按日分组的流水列表
│    └── 悬浮「+」记账按钮
├── 📊 报表
│    ├── 月/年切换
│    ├── 收支概览
│    ├── 分类占比环形图
│    └── 趋势图 + 分类排行
└── ⚙️ 我的
     ├── 预算设置
     ├── 分类管理
     ├── 记账提醒
     └── 数据导出/备份
```

## 5. 非功能性需求

| 类别 | 要求 |
|---|---|
| 性能 | 冷启动 ≤ 2 秒；1 万条记录下列表滑动流畅、报表渲染 ≤ 1 秒 |
| 数据安全 | 数据本地加密存储；支持 App 锁（PIN/指纹/面容，P2） |
| 隐私 | 不收集用户消费数据上传服务器；无第三方广告 SDK |
| 兼容性 | iOS 15+ / Android 10+；适配主流机型与深色模式 |
| 可用性 | 支持离线使用（V1.0 全功能无需网络） |

## 8. 风险与应对

| 风险 | 说明 | 应对策略 |
|---|---|---|
| 用户坚持不下来 | 记账类产品普遍 7 日流失严重 | 极简流程 + 记账提醒 + 连续记账天数激励（P2 考虑） |
| 数据丢失 | 本地存储换机/卸载导致数据丢失 | 强化备份导出引导；V2.0 提供云同步 |
| 同类竞品成熟 | 随手记、鲨鱼记账等竞品功能全面 | 差异化主打「极简 + 隐私（纯本地）」 |
